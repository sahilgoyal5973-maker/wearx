# AGENTS.md

## 1. Project Overview
WearX is an online fashion and clothing brand based in Southwest Delhi, offering a curated collection of Casual Wear, Ethnic Wear, Sportswear, Party Wear, and Winter/Seasonal Wear for both men and women.

## 2. Audience
The primary audience is fashion-conscious men and women aged 18 to 40 in and around Southwest Delhi. The conversion goals are (a) an enquiry form submission (lead generation) and (b) add-to-cart and checkout for e-commerce purchases.

## 3. Primary Goal
Every page must encourage the visitor toward browsing collections, adding items to the cart, and submitting the enquiry / checkout form.

## 4. Tech Rules
- Plain HTML, CSS, and JavaScript only.
- No frameworks, no build step, and no external UI libraries.
- One shared `style.css` and one shared `script.js`.
- Mobile-first CSS.
- Semantic HTML5 tags.

## 5. Working Rules
- Build one page at a time.
- Never create files that were not explicitly asked for.
- Explain what you changed after each task.
- Ask any question needed before proceeding if requirements are unclear.
